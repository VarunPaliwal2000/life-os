========================================
REQUEST FLOW
========================================

Browser

GET /api/health

    ↓

index.ts

(Server already running)

    ↓

app.ts

app.use("/api", healthRouter)

    ↓

health.ts

router.get("/health")

    ↓

res.json(...)

    ↓

Browser

========================================
ROUTING EXAMPLES
========================================

Example 1

app.ts

app.use("/api", healthRouter)

health.ts

router.get("/health")

URL:

/api/health


----------------------------------------

Example 2

app.ts

app.use("/api", healthRouter)

health.ts

router.get("/hello")

URL:

/api/hello


----------------------------------------

Formula

app.use("/prefix")

+

router.get("/route")

=

/prefix/route

========================================
DATABASE USER
========================================

Purpose:

Used by application to access database

Created In:

    ↓
Security
    ↓
Database Access

Example:

lifeos_admin

********

Notes:

- Password can be reset.
- Application uses this user to connect.

Notes:






========================================
CONNECTION STRING
========================================

Purpose:

Address used to connect application
to MongoDB

Example:

mongodb+srv://username:password@cluster.mongodb.net

Flow:

Node
    ↓
Mongoose
    ↓
MongoDB Atlas
    ↓
Cluster

Notes:

- Contains username
- Contains password
- Should never be hardcoded

Notes:
